## 8. 기타 유용한 자료

### ROS2 패키지

```bash
# 유용한 패키지들
sudo apt install -y \
  ros-humble-plotjuggler \         # 데이터 플롯
  ros-humble-rqt-multiplot \       # 멀티 플롯
  ros-humble-nav2-simple-commander # 간편 Nav2 API
  ros-humble-twist-mux             # 다중 cmd_vel 소스 관리
  ros-humble-imu-filter-madgwick   # IMU 필터
  ros-humble-robot-localization    # 센서 퓨전 (EKF)
```

### ROS2 팁

```bash
# 자주 사용하는 alias (bash_aliases)
alias cw='cd ~/ros2_ws && colcon build --symlink-install'
alias sw='source ~/ros2_ws/install/setup.bash'
alias tb3='export TURTLEBOT3_MODEL=burger'
alias bringup='ros2 launch turtlebot3_bringup robot.launch.py'
alias teleop='ros2 run turtlebot3_teleop teleop_keyboard'
```
