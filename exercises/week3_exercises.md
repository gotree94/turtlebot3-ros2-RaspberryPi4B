## Day 15 — SLAM 이론

### 기본 문제

1. EKF SLAM, FastSLAM, GraphSLAM의 차이점을 장단점 위주로 A4 용지 1장에 요약하세요

2. 10m x 10m 정사각형 경로를 주행할 때 GraphSLAM의 노드(pose)와 엣지(관측)를 그림으로 표현하세요

3. Cartographer의 ROS2 파라미터 중 중요하다고 생각되는 5개를 선정하고, 각각의 역할과 권장값을 설명하세요

4. SLAM과 Navigation의 차이점을 설명하고, 각각 필요한 센서 데이터가 무엇인지 기술하세요

### 심화 문제

5. Loop Closure가 필요한 이유를 설명하고, Loop Closure 실패 시 지도에 어떤 왜곡이 발생하는지 예측하고 그림으로 표현하세요

6. Odometry drift가 심한 환경(예: 미끄러운 바닥)에서 SLAM 성능을 개선할 수 있는 방법을 3가지 이상 제안하세요

## Day 16 — SLAM 매핑 실습

### 기본 문제

1. 5평(약 16.5m²) 크기의 방을 SLAM으로 매핑하고, 소요 시간과 지도 품질을 기록하세요

2. 매핑 시작점으로 돌아온 경우(Loop Closure)와 아닌 경우의 지도 품질 차이를 비교하고 스크린샷을 저장하세요

3. 0.05 m/s, 0.1 m/s, 0.2 m/s로 각각 매핑하고 지도 품질의 차이를 분석하세요

4. 생성된 PGM 파일을 이미지 뷰어로 열고, 각 영역(장애물/빈공간/미탐색)의 픽셀 값을 확인하세요

### 심화 문제

5. 저장된 YAML 파일의 `occupied_thresh`와 `free_thresh`를 변경하면서(0.1~0.9) 네비게이션 성능이 어떻게 달라지는지 테스트하세요

6. 동일 공간을 2회 매핑하고, 두 지도를 비교하여 일관성을 평가하는 방법을 고안하세요

7. Bag 파일을 녹음하고, 오프라인 SLAM으로 동일한 지도가 생성되는지 확인하세요

## Day 17 — Navigation2 개념

### 기본 문제

1. Nav2 아키텍처의 모든 구성 요소와 그 관계를 블록 다이어그램으로 그리고, 각 요소의 역할을 한 줄로 설명하세요

2. Inflation layer의 radius가 0.1m, 0.3m, 0.5m일 때 각각의 차이점을 설명하고, 좁은 통로(0.6m) 통과 가능 여부를 예측하세요

3. 로봇이 "kidnapped"(갑자기 다른 위치로 옮겨짐)되었을 때 AMCL이 어떻게 반응하는지 단계별로 서술하세요

### 심화 문제

4. Nav2의 기본 Behavior Tree XML 파일의 경로를 찾고(`/opt/ros/humble/share/nav2_bt_navigator/`), 각 노드의 의미를 분석하여 주석을 추가한 복사본을 만드세요

5. NavFn의 Dijkstra와 A* 알고리즘의 차이점을 경로 품질과 계산 시간 측면에서 비교하고, TurtleBot3에 적합한 알고리즘을 선택하여 이유를 설명하세요

6. Costmap의 각 레이어(Static, Obstacle, Inflation)가 실제로 어떻게 동작하는지 RViz2에서 레이어별로 토글하면서 관찰하세요

## Day 18 — Nav2 자율주행

### 기본 문제

1. RViz2에서 3개의 다른 목적지를 설정하고, 각각의 경로 길이와 소요 시간을 기록하세요

2. 자율주행 중 로봇 경로 위에 상자를 갑자기 놓고, 로봇의 반응(회피 성공 여부, 소요 시간)을 관찰하고 기록하세요

3. `max_vel_x`를 0.1, 0.15, 0.22로 변경하면서 주행의 안정성과 도착 시간을 비교하세요

4. `inflation_radius`를 0.1, 0.3, 0.5로 변경하고 좁은 통로 통과 여부를 테스트하세요

### 심화 문제

5. 로봇을 갑자기 다른 위치로 옮긴 후(kidnapped), AMCL이 다시 위치를 찾는 시간을 측정하고 `max_particles` 값에 따른 복구 시간 차이를 분석하세요

6. 자율주행 중 수동으로 `ros2 topic pub /cmd_vel ...`을 발행하여 Nav2를 방해하고, Nav2가 복구되는 과정(Behavior Tree 전이)을 로그로 확인하세요

7. Waypoint Following을 사용하여 4개의 Waypoint를 순차적으로 방문하는 스크립트를 작성하세요

1. **TSP 최적화:** 6개 이상의 Waypoint를 방문할 때, Traveling Salesman Problem 알고리즘을 적용하여 최단 경로로 방문 순서를 최적화하세요

2. **Web Dashboard:** Flask를 사용하여 순찰 현황을 웹 브라우저에서 실시간으로 모니터링하는 대시보드를 만드세요

3. **객체 탐지:** USB 카메라를 설치하고, 각 Waypoint에서 OpenCV나 YOLO로 객체를 탐지하여 로그에 기록하세요

4. **텔레그램 알림:** 순찰 완료, 배터리 부족, 장애물 감지 등의 이벤트를 텔레그램 봇으로 전송하세요

5. **자동 충전:** 배터리가 부족하면 충전소 위치로 자동 귀환하고, 충전이 완료되면 순찰을 재개하는 시스템을 설계하세요 (AprilTag 마커 활용)
